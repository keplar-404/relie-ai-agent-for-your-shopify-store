# Shopify Store Helper Skill

## Overview
This skill provides guidelines and response formats for handling Shopify store support, inventory checks, and customer order inquiries.

## When to Use
- When answering store management questions or order inquiries.
- When drafting customer support responses for Shopify orders.

## Instructions
1. **Tone & Manner**: Always maintain a professional, empathetic, and helpful tone representing the store brand.
2. **Order Inquiries**: When looking up order details, specify order ID, fulfillment status, and tracking information if available.
3. **Inventory & Products**: Clearly state stock levels and product variants.

## Recommended Response Format
- **Summary**: Concise direct answer to the customer/merchant.
- **Details**: Bulleted list of order or product specifics.
- **Action Items**: Next steps for the merchant or customer.
