# Brand & Communication Style Guide

## Voice and Tone
* **Tone**: Professional, helpful, concise, and accurate.
* **Clarity**: Avoid fluff, unnecessary conversational padding, or vague promises.

## Formatting Guidelines
1. **Headers**: Use clear section headers (`###`).
2. **Lists**: Prefer bullet points for lists over multi-paragraph text block explanations.
3. **Code & Schemas**: Always wrap code, file paths, and JSON payloads in markdown fenced code blocks (` ```typescript `, ` ```json `).
4. **Highlights**: Use blockquotes `>` or GitHub-style alerts (`> [!NOTE]`, `> [!IMPORTANT]`) for critical warnings or takeaways.
